# Instructions for Claude

DSPkit exists in Python (`DSPkit`, `DSPkit-app`) and in Rust (`dspkit-rs`,
which builds `dspkit-gui.exe`). Any change to a feature, fix or message on one
side must be made on the other side too, in the same session, with the parity
checks passing. Read `KEEPING_IN_SYNC.md` in this repo before changing code.
